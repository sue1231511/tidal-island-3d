# 游戏时钟

来源：游戏服务端 `allotment-relay/server/world.py`、`season.py`、`config.py`（2026-10 核对）。

所有状态都只由**当前时间**决定，不需要连服务器，在浏览器里就能算出和游戏一模一样的结果。`t` = Unix 时间戳（秒，UTC 纪元）。

| 维度 | 周期 | 公式 | 顺序 |
|---|---|---|---|
| 时辰 | 每段 2400 秒（40 分钟） | `floor(t / 2400) % 3` | 0 昼 `day` → 1 暮 `dusk` → 2 夜 `night` |
| 潮汐 | 每段 3600 秒（1 小时） | `floor(t / 3600) % 3` | 0 退潮 `ebb` → 1 平潮 `slack` → 2 涨潮 `flood` |
| 天气 | 每段 7200 秒（2 小时） | `floor(t / 7200) % 3` | 0 晴朗 `clear` → 1 海雾 `misty` → 2 阵风 `gale` |
| 季节 | 每段 7 天 | 东八区自 `2026-01-05 00:00 +08:00`（周一）起算的整天数 `d`，`floor(d / 7) % 4` | 0 春 → 1 夏 → 2 秋 → 3 冬 |

- 本季剩余天数：`7 - (d % 7)`（含今天，取值 1～7）。
- 游戏里状态是**到点硬切换**的。画面要不要在交界处平滑过渡、过渡多久，你自己决定，但“当前是哪个状态”必须和公式一致。
- 东八区 2026-10-05 01:16 用公式核对的结果是：冬、暮、涨潮、阵风。可以拿来自测。

注意：时辰只有三段，各 40 分钟，一轮 2 小时。它和现实的白天黑夜无关。

## 每个状态在游戏里意味着什么

下面是游戏给人类看的木牌原话，可以拿来给地点卡片配文，也可以帮你想画面。

### 时辰

- **昼**：斑鸠只在这时出现。酒吧默认打烊。
- **暮**：酒吧开门。意外略高。
- **夜**：酒吧继续开。户外长得稍快。

### 潮汐

- **退潮**：能赶海。崖上铁砂更肥。
- **平潮**：能掏洞。崖上铜绿略肥。
- **涨潮**：赶海和掏洞都不行。盐脉更肥，盐田只能这时灌。

### 天气

- **晴朗**：地里长得稳，赶海贝壳多一点。
- **海雾**：打理过的地慢一点。出海多花时间，酒吧小费好一点。
- **阵风**：没人看的地疯长，也更容易出事。出海容易失败，岸工坊能打捞。

### 季节

一周一季。温室不受季节影响。

- 春：虫害潮、花粉潮、春汛
- 夏：常干旱，也有热浪、渔汛、雷暴、赤潮
- 秋：秋台、落叶、畜瘟潮
- 冬：霜冻、雪封、北风

（这些周气候事件由服务端随机抽，离线算不出来。只当季节氛围的参考就行，不要求实现。）
