## 地上：14 处

方位按总览图，北在上。括号里是总览图上的副标题。

| 地点 | 方位 | 是什么 |
|---|---|---|
| 岸畔小屋（管理员的家） | 西北 | 岛民自己的家。能睡、能做饭。游戏里会从棚屋一路升级成临海邸 |
| 份地（种植与收获） | 北，偏中 | 菜地、果园、温室，旁边有风车 |
| 海边（拾贝·垂钓·发呆） | 东北 | 沙滩加港口码头。撒网、坐钓、开船、赶海。潮汐对这里影响最大 |
| 盐风崖（眺望与思考） | 西，崖边 | 挖矿的崖：铁砂、铜绿、盐脉。涨潮出盐，退潮出铁，海雾出稀有 |
| 岸工坊（修理·改造·制作） | 东，海边下方 | 打铜钉、补网、盐田、阵风后打捞 |
| 广场（岛屿的中心） | 正中 | 圆形大广场。里面有杂货铺、灯塔、乔乔诊所、潮汐公告、栗栗流动摊 |
| 酒吧（微醺·故事·相遇） | 西，广场左 | 滨海酒吧。暮和夜开门，岛民来洗碗上工、点酒 |
| 剧场（小橘星光） | 东，广场右 | 红顶剧场，门头有星。里面有编剧社、衣泊坊、剧场看台 |
| 集市（交易·热闹·人情） | 西南 | 条纹摊篷的集市，旁边有默语花房 |
| 小馆（简餐·茶饮·小憩） | 东南 | 岸畔小馆，堂食 |
| 听潮亭（静听潮声） | 南，偏中 | 一座亭子，木牌墙，岛民钉牌问事 |
| 潮生会（岛民组织） | 东南，听潮亭右 | 会堂。交岸税、捐基金、看告示 |
| 连理所（缔结·纪念·誓约） | 西南角 | 开花的拱廊。订婚、成婚 |
| 井下入口（深入之地） | 最南 | 山洞口，往下通井下世界 |

灯塔在游戏里是广场下面的一个子地点，总览图上看不到实体。要不要把它单独立在海岬上，你和她商量。

## 地下：井下世界

总览图从上到下大致是这样。整体是一个往下挖的洞穴群：有石阶、栈道、灯笼、藤蔓，还有地下水和瀑布。

| 地点 | 位置（井下总览图） | 是什么 |
|---|---|---|
| 井下入口 | 最顶上，竖梯下来 | 从地面下来的地方 |
| 后室铺 | 左上 | 帘子后的杂货铺，能买、能修 |
| 恩怨墙 | 中上 | 一面贴满悬赏的墙，接单、挂单 |
| 恶猫钱庄 | 右上 | 钱庄，查账、借还、存取 |
| 深坑 | 左中 | 下沉的圆形角斗场，一圈圈石阶 |
| 死人赌场 | 右中 | 赌场，骰子、灯、抽牌。荷官叫 Silas |
| 凯斯酒馆 | 正中 | 井下的酒馆 |
| 晏安医务间 | 右下 | 治井下伤的诊室 |
| 地下监牢 | 左下 | 铁栏围起来的牢 |
| K 室 | 最底 | 最深处一扇圆门，帘幔、贝壳和灯 |

井下在游戏里是“减岛缘”的高风险区，氛围上可以比地面更暗、更神秘，但不用做得吓人。原图里它其实挺好看。
